# Poängtavlans databas

**Läge 2026-10-21:** [poangtavla.html](poangtavla.html) har ingen databas just nu. Sidan
laddar men visar "Kunde inte hämta poängen" tills en ny databas finns.

Tabellen `poang` låg i Wineographs Supabase-projekt (`uzsapdhydpfxjyufzgji`), där den inte
hör hemma. Den saknade dessutom RLS, så vem som helst med den publika nyckeln kunde ändra
eller tömma den. Supabase varnade för det. Tabellen var tom och togs bort.

## Inför nästa gång

### 1. Eget Supabase-projekt

Skapa ett nytt projekt på supabase.com (gratisnivån räcker), t.ex. `babatravels`. Lägg det
inte i Wineographs projekt igen.

### 2. Tabellen

Kör i SQL Editor → Run:

```sql
create table public.poang (
  id         bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  event      text not null,   -- t.ex. 'beer-run-2026', så att flera evenemang kan dela tabell
  gubbe      text not null,
  gren       text not null,
  poang      int  not null
);

-- Sidan får bara läsa, lägga till och ta bort rader (Ångra / Nollställ). Ändra och tömma är stängt.
alter table public.poang enable row level security;
create policy "poang läses"      on public.poang for select to anon using (true);
create policy "poang läggs till" on public.poang for insert to anon with check (true);
create policy "poang raderas"    on public.poang for delete to anon using (true);

grant select, insert, delete on public.poang to anon;
revoke update, truncate on public.poang from anon, authenticated;

-- Alla telefoner uppdateras direkt när någon ger poäng.
alter publication supabase_realtime add table public.poang;
```

### 3. Koppla sidan

I [poangtavla.html](poangtavla.html), ändra:

- `SUPABASE_URL` till det nya projektets URL (Project Settings → API).
- `SUPABASE_KEY` till det nya projektets **publishable**-nyckel (`sb_publishable_…`), aldrig
  secret-nyckeln. Den publika nyckeln får synas i källkoden.
- `EVENT` till ett nytt namn om det är ett nytt evenemang.

Kolla att `gubbar` och `grenar` stämmer för det nya evenemanget.

### 4. Testa

Öppna sidan på två telefoner. Ge en poäng på den ena och se att den dyker upp på den andra.
Prova sedan Ångra.

Kolla också under Advisors → Security Advisor i Supabase att `poang` inte flaggas.
